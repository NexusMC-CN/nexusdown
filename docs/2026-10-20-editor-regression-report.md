## 已复现并修复的问题

| 场景 | 根因与修复 | 验证 |
| --- | --- | --- |
| 长文档开头输入中文，随后撤销，编辑区出现错字或布局异常 | 组字期间旧装饰没有随文档修改映射，隐藏标记可能覆盖换行，触发 `Decorations that replace line breaks may not be specified via plugins`。现在组字期间只映射装饰位置，结束后再重建。 | 浏览器复现原故障；回归测试覆盖输入和撤销，修复后同场景无新增控制台错误。 |
| 组字结束时最后一次 DOM 修改尚未提交 | 主动刷新不能抢在 CodeMirror 提交最终字符之前。现在等待测量周期先提交 DOM 输入，再补预览刷新，并取消已销毁实例的延迟事务。 | 真实 DOM / MutationObserver 测试验证 `plainn` 最终正确变成 `plain你`，无须模拟 composing getter。 |
| 多个编辑器同时存在时，组字期间换稿串写或丢失 | 待同步值原来是模块级全局字符串。现在按 EditorView 隔离，保留最新外部替换，等待期间暂停旧稿回流。 | 两编辑器隔离、空稿、取消旧值、连续组字与 v-model 回流测试。 |
| 从页签源码模式切换到新草稿，新文档一直显示源码 | 旧源码编辑范围映射到新文档后覆盖整篇。实际换稿时清除旧 `editingRange`、`editingBlock`，同值回填不清除。 | 单测检查新公式 widget 恢复；浏览器验证页签编辑后切换公式样例。 |
| 在正文中间插入代码块或表格，预览结构错误 | 块语法直接拼在正文中间。现在补齐独立行与必要空行；选区终点落在下一行行首时不再误处理下一行。 | 单光标、多光标、反向选区、边界插入与实际 Markdown 渲染测试；浏览器工具栏插入验证。 |
| 点击第二或第三个页签的代码，修改落到前一个属性行 | 闭围栏被再次当成开围栏，源码偏移计算错误。现在成对扫描围栏，支持不同围栏字符与长度。 | 三页签、波浪线围栏、长围栏和内部较短围栏测试；浏览器验证编辑第二页签只修改对应代码。 |
| 点击公式无反应，或之后输入仍留在编辑器外 | 块装饰漏掉 `editingBlock` 变化；点击也没有恢复焦点。现在同步刷新并聚焦编辑器。 | 光标已在公式前空行、外部输入框持有焦点两类回归；浏览器点击验证。 |
| 预览刷新覆盖后发生的滚动 | 每次更新都排队恢复旧 `scrollTop`，可能撤销光标跟随或后续手动滚动。移除强制回滚，保留 CodeMirror 自身的滚动锚定。 | 测量时序回归；浏览器验证长文档翻页、跳转首尾和输入撤销。 |
| 手机宽度出现整页横向滚动条 | 隐藏的绝对定位工具提示也扩大页面滚动范围。改为固定定位，并按按钮实际位置限制到视口内，支持鼠标与键盘触发。 | 390px 视口下页面宽度由 456px 降为 375px；提示框保持在视口内；1280px 桌面复核。 |

## 验证边界

浏览器中文输入通过自动化输入完成；组字状态另有真实 DOM 事件和部分状态模拟测试，未验证 Windows 拼音候选窗口或真实移动设备输入法。没有执行发布或线上部署。

`setEditorValue` 将不同内容视为外部全文替换，组字期间采用外部换稿优先语义；消费方应在组字结束后再做全文规范化。普通 v-model 原值回填正常支持。

参考了 [codemirror-live-markdown](https://github.com/blueberrycongee/codemirror-live-markdown) 的交互状态与装饰失效处理，并保留本项目现有架构。截图中图片在编辑区和输出区的布局差异属于现有渲染能力差异，本轮未实现编辑区轮播。
