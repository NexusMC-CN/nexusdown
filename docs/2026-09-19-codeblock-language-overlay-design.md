# 代码块语言菜单顶层浮窗设计

## 目标

代码块语言按钮仍固定在当前代码块右上角。展开后的语言菜单成为独立浮层，不参与富文本编辑区布局，不改变编辑器宽高，也不受编辑器滚动容器、分栏或底部状态栏裁切。

## 组件边界

- `CodeBlockLanguage.vue` 继续负责识别当前代码块、显示触发按钮和执行语言切换。
- 触发按钮保留在富文本内容层中，以便跟随代码块位置。
- 语言菜单通过 Vue `Teleport` 挂载到 `resolveOverlayTarget()` 返回的目标；普通页面使用 `document.body`，原生模态 `dialog` 内使用该 `dialog`，避免浮层落到浏览器顶层之后。
- 复用 `useNexusdownViewport()` 监听窗口、滚动、方向和移动端可视视口变化。
- 复用 `useNexusdownOverlayTheme()` 与 `nexusdownThemeVariables()`，让被传送的菜单持续继承所属编辑器的亮暗主题、自定义皮肤变量和字体。

## 定位行为

- 菜单使用 `position: fixed` 和独立高层级，不进入编辑器文档流。
- 水平位置与语言按钮右边缘对齐，并在可视视口左右各保留至少 8px。
- 默认在按钮下方留 6px 展开；若下方容不下菜单，则改在按钮上方展开。
- 菜单最大高度同时受现有 220px 上限和当前可视视口可用空间限制，超出时只滚动菜单自身。
- 编辑器或页面滚动、窗口缩放、设备方向变化时重新测量锚点；代码块离开当前选择或编辑器进入只读状态时关闭菜单。

## 交互与可访问性

- 触发按钮提供 `aria-expanded`，菜单使用 `role="menu"`，选项使用 `role="menuitemradio"` 和 `aria-checked`。
- 点击外部或按 `Escape` 关闭；选择语言后关闭并保持现有 Markdown 同步行为。
- 菜单与触发按钮都视为组件内部区域，点击菜单不会被外部点击处理提前关闭。

## 测试与验收

- 先增加失败测试，证明菜单当前仍位于编辑器内部且为绝对定位。
- 组件测试验证菜单被传送到编辑器外部、固定定位、主题变量继承、语言选择正常，以及空间不足时向上翻转。
- 样式契约同时验证 `src/style.css` 与 `public/style.css`，两份发布样式保持一致。
- 最终运行 Vitest、TypeScript 类型检查、Vue 类型检查、构建、示例构建、npm dry-run 打包和 `git diff --check`。

## 非目标

- 不重做语言列表或代码高亮方案。
- 不改变代码块按钮的视觉规格。
- 不修改编辑器高度、分栏比例、滚动同步或状态栏行为。
